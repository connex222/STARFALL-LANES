# STARFALL LANES

A TV/phone strategy game for 2-8 players. Install Node.js 18+, run npm install, npm start, then open the local URL on TV and join by phone. Render deploy: build npm install --omit=dev, start npm start. For changes edit src/, run npm run build; validate with npm test. Full human multiplayer testing remains outstanding. The 72 portraits are at public/art/avatars/. Original PNGs remain in Git history; phase history is at docs/changelog/.
