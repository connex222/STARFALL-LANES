## Host checklist

- [ ] Before starting, open the host menu on your phone and enable **Playtest log**.
- [ ] Run a game without coaching unless someone asks a question; note the question.
- [ ] At Game Over, download **playtest log (JSON)** and **playtest summary (Markdown)** on the TV (host phone also offers backups).
- [ ] Save these files with the sheet and identify patterns in slow rounds, failures and enjoyment.
- [ ] Repeat with 2, 4 and 6–8 people before changing the game rules.

**Privacy:** Playtest Mode is off by default and records gameplay events in server memory until the room is discarded. Exports may include players' chosen display names. Ask participants before sharing logs outside your group. It does not upload telemetry to any third-party service.
